## Product brief
CoupleGames is a mobile/tablet-first mini-game hub. Săn Số: find numbers 1..100 on a messy handwritten notebook, server arbitrates first valid claim, both players see results immediately. Supports 2–3 players or a host spectator + two players, room invites, lock/kick/leave/close, rematch, avatar reactions 😆/🍅/💗, sticky target-number HUD. Later: Caro (turn-based 2p), Gián Bom battle (2p), Tank (4–5p and spectator).

## Critical CURRENT operating state
- **Production** `https://couplegames-vn.vercel.app` remains old v0.4.1 HTTP/Blob backend; room creation was seen returning **503**. Vercel runtime reports `Vercel Blob: This store has been suspended`; store `couplegames-room-state` reports `billingState=suspended`, `usageQuotaExceeded=true`, `status=limits-exceeded-suspended`. Avoid further hot-path Blob usage; do NOT create a new store just to bypass the quota.
- **Cloudflare pilot** is implemented on GitHub only, **not yet deployed** to a Cloudflare account; no `workers.dev` URL exists that has been verified in chat.
- `cloudflare/src/index.js`: Worker routes HTTP and a WebSocket to room Durable Objects.
- `cloudflare/src/engine.js`: pure authoritative Săn Số Classic rules; 2-hour TTL.
- `cloudflare/public/online.html`: cloud-specific multiplayer UI with socket push and HTTP fallback, sticky HUD, avatar emotes.
- `cloudflare/wrangler.jsonc`: Workers + SQLite-backed Durable Objects binding `ROOMS`, static assets. `ALLOWED_ORIGIN` targets existing Vercel domain.
- Cloudflare pilot **does not implement Gián Bom, Caro, Tank**, nor confirmed multi-device production latency.

## What has been TESTED (actual evidence)
- Pure engine: **8/8 `node --test` PASS** on Wrangler local setup.
- `wrangler dev --local`: health HTTP 200; DO binding and static assets recognized.
- Three clients in one local test environment (guest A, guest B, spectator host): all WebSockets received `game.started` and `number.claimed` events; duplicate claim HTTP 409; reaction cooldown HTTP 429; room closure invalidated late join HTTP 410.
- Local same-runtime event push ~**11ms** (not mobile/Internet p95).
- `wrangler deploy --dry-run` passed. CORS allowed old Vercel origin in local Worker response.
- Socket cap and rate-limiting safeguards added after the local E2E; final changes need rerunning integration tests in the next PC session. A `test/smoke.mjs` runner was added for reproducibility.
